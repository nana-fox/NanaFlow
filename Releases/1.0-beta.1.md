# NanaFlow 1.0-beta.1

NanaFlow 是原生 macOS 专注计时器。这是首个公开测试版，应用内版本为 1.0 (3)，最低支持 macOS 15。

安装包为本 Release 附件中经 Developer ID 签名并公证的 ZIP：解压后将 NanaFlow.app 拖入“应用程序”。也可按 [README](https://github.com/nana-fox/NanaFlow/blob/v1.0-beta.1/README.md) 的说明自行构建；未使用匹配证书和 profile 的构建，无法使用 App Group、iCloud 等系统能力。

## 本版内容

- 25/5/30 默认周期，支持暂停、继续、跳过、重置和自动开始。
- 主窗口内 D/W/M/Y 统计，可切换次数或净专注时长。
- 专注与休息可分别选择完成声音，音量分五档。
- 状态栏倒计时，可选显示今日完成数（如 `25:00 | 3`）。
- 手动跳转阶段后立即开始下一阶段。
- 可从旧版 NanaFlow 手动导入数据。

## 尚未验收

以下三项已决定延后，不阻塞本次 Beta，但**没有通过验收**：

1. **通知动作**：通知卡片上的打开、开始、跳过等动作，以及前台显示。
2. **Widget**：实际画面与刷新。
3. **声音**：完成提示音的实际播放。

遇到这几方面的问题时欢迎反馈。

## 从旧版导入数据

入口：「设置 → 旧版数据 → 导入旧版数据…」。此功能只面向旧版 NanaFlow，不支持导入 Flow 或其他应用的数据。

导入前：

1. 在旧版中暂停计时，关闭“启动时开始计时”“启动时重置周期”和定时器同步，然后退出旧版。
2. 把 `~/Library/Preferences/com.nanafox.NanaFlow.plist` 复制到其他位置留作备份，导入时选择这份副本。
3. 确认新版没有运行中的计时。

边界：

- 只读取计时状态、偏好、会话历史（三者必需）和标签（可选），文件上限 16 MiB。
- 不合并也不覆盖。如果新版已有不同的数据或已有会话历史（包括 Widget 共用副本中的历史），导入会被拒绝。
- 校验不通过时不做任何更改；写入后读回失败时会尝试撤销，但这不是崩溃安全事务。
- 不要依赖首次启动的系统自动迁移。它在维护者的一次真实升级中未生效，原因尚未确定。
- 导入机制已在较早候选 1.0 (1) 上用一台 Mac 的真实数据验证并重开核对；1.0 (3) 已通过本次导入保护回归。其他旧版本和数据形态未覆盖。

## 已知限制

- 主历史缺失而 Widget 镜像为空的特定场景，旧版导入可能被保护规则拒绝；这是代码审查发现的边界，尚未实机覆盖。请保留原数据文件。

- 本版与提交 App Store 的 NanaFlow 1.0.0 (2) 来自不同代码分支，功能范围不同，但 Bundle ID 相同，共用同一沙盒容器。请不要同时使用两者。
- 本版本没有内置更新机制，需要手动更新。回退旧版前请保留两边的数据，不要用旧备份覆盖新增记录。
