# NanaFlow 菜单栏设计

## 常驻展示

- 默认只显示倒计时文字，例如 `25:00`；不显示 NanaFlow 半圆标记或其他品牌图形。
- 运行中：倒计时使用绿色强调色，秒数实时更新。
- 暂停：保留当前时间，展开菜单的首项变为“开始”。
- 休息：显示休息剩余时间，展开菜单标题改为“休息 · 05:00”。
- 关闭主窗口后：菜单栏项目继续存在，可通过“显示计时器”恢复窗口。

## 展开菜单

1. 当前阶段与剩余时间。
2. 开始或暂停。
3. 显示或隐藏计时器。
4. 显示统计。
5. 跳到休息或跳到专注。
6. 重新开始。
7. 计时设置、应用设置、关于。
8. 退出 NanaFlow。

明确不提供迷你计时器、阻断器、洞察、标签或独立历史入口。
