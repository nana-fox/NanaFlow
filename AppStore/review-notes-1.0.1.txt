NanaFlow 1.0.1 (4) updates the existing menu-bar focus timer. No account or sign-in is required.

Launch NanaFlow and choose OK in the first-launch welcome screen. This is a menu-bar utility with no Dock icon. Left-click the countdown and choose Show Timer if its window is hidden. Right-click or Control-click the countdown to start or pause.

Use the circular button to start/pause. The chart button opens day/week/month/year statistics in the same window. The metric selector switches between completed focus sessions and net focus time. Settings contains separate focus/break completion sounds and notification preferences. Notifications remain off by default; enabling them requests macOS permission, and the app works if permission is denied.

This update refines window edges/dragging, localization/version information, statistics, sound-volume consistency and completion-notification scheduling. The existing Widget extension and local App Group storage remain. There is no Calendar integration, iCloud sync, blocker, paywall, tag workflow or online account service. Session-list browsing and JSON backup/import are not advertised as accessible features in this store UI.

The English and Simplified Chinese interfaces provide the same core features in every configured territory. App text and Widget quotations are NanaFlow-authored; Phosphor Icons are used under their included license. No third-party online service is required.
